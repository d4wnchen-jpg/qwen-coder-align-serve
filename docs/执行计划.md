## 风险与应对

| 风险 | 应对 |
|---|---|
| 8B bf16 在 4090 上 OOM（长上下文/大批量） | 减小 cutoff_len（2048→1024）、batch 减半；或开 4bit QLoRA |
| AWQ 社区权重不存在 | 用 llm-compressor / autoawq 自己量化（脚本预留位置），或直接用 FP8 |
| vLLM 版本 API 变化 | `serve/*.sh` 内注释标明验证版本；升级后先 `vllm bench --help` 核对参数 |
| EvalPlus 数据污染 | 固定用 EvalPlus 的 plus 版本（防泄漏），训练数据过滤与测试题近重复样本 |
| 租卡机国内网络 | HF 走 hf-mirror 镜像（`HF_ENDPOINT=https://hf-mirror.com`）；pip 用清华源 |
| Qwen3-8B 无原生 MTP（2026-08-18 已实测验证） | 投机解码改用 EAGLE3（vLLM 官方 qwen3_eagle3 实现，需 draft 权重）或 ngram（零成本） |
